# dsh-superagent playground

This repository is the working target for the `dsh-superagent` instance.

## Try it

Open an issue or comment with:

```
@yangxiqwer Please add a short "Getting started" section to this README.
```

The agent will acknowledge the request, work in its own branch, and open a pull request for review.

## Notes

- Default branch: `main`
- Agent branch prefix: `agent/`
- Auto-merge: disabled; a person reviews and merges.
